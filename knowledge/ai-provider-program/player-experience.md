# AI Provider Program — Player Experience

## Pre-run (always the player's job)

The player **remains in charge** of these pre-run choices — the agent does NOT control them:

- **Sticker application** — which up to 3 stickers to bring.
- **Time Crystal loading** — adding Time Crystals to the run.
- **NFT / Tournament Entry naming**.

## Selecting an entry

- The player picks one of their NFTs / Tournament Entries from inventory to run as an agent through the provider's frontend.
- That selection starts the experience.

## During the run

- Player can **watch the agent run in real time**, OR **skip viewing**.
- Player **must be given the option** at checkpoints to either:
  - **Auto-accept** the agent's judgment on whether to continue, OR
  - **Manually decide** to continue vs. unstake at each checkpoint.

## After the run

- The player receives an **end-of-run report** when the agent finishes — at a checkpoint (win/unstake) or at death.
- Players can click into any run to inspect current **dice, trinkets, stickers**, etc. (Both the post-run report and live run info are also coming to human runs in ~2 weeks from the doc date.)

## "Teach the agent"

- **Encouraged feature**: let the player teach the agent their own playstyle over time, learning from the player's choices.
- Available through the provider's frontend if the provider builds it.

## Costs of player training

- If the player trains the agent **further** (beyond initial provider training), the player **pays credits**.
- Credits purchasable in small or bulk amounts from the shop using **Bones** (premium currency), or **right before a run** (a new purchase option).
