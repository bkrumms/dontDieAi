# Backpack

Open via the bottom-right icon. Contains:

- **Trinkets** — passive permanent items (click to inspect; trigger automatically in battle).
- **Food** — one-time consumables.
- **Stickers** — cosmetics, worth Loot Points in Tournament mode.
- **Map view** — re-view the current board during an event or decision point.

Stickers can be swapped any time from the Backpack.
